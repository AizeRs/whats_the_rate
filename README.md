# What's the Rate 

**What's the Rate** — это веб-приложение для отслеживания актуальных курсов валют, криптовалют и акций, а также для добавления их в собственные инвестиционные портфели для удобного мониторинга их стоимости.

---

## Технологический стек


**Backend:**
- **Язык:** Python 3
- **Фреймворк:** Flask
- **База данных:** SQLite + **SQLAlchemy (ORM)** — для безопасного и удобного взаимодействия с базой данных.
- **Сетевые запросы и асинхронность:** `requests`, `aiohttp` — для сбора рыночных данных из внешних API.
- **Авторизация:** `Flask-Login` (управление сессиями), `Flask-WTF` / `WTForms` (безопасные формы), `Werkzeug` (хэширование паролей).

---

## Ключевой функционал

- **Система аккаунтов:** Регистрация, безопасная авторизация и управление личным профилем.
- **Рыночные котировки:** Просмотр списков доступных акций, криптовалют и фиатных валют.
- **Инвестиционные портфели:** Возможность создания пользовательских портфелей, добавления в них активов и отслеживания их стоимости.
- **Удобная навигация:** Поиск активов (в том числе фильтрация по алфавиту) и интуитивно понятный пользовательский интерфейс.
- **Собственное API:** Наличие внутренних REST-эндпоинтов для взаимодействия компонентов.

## Как запустить проект (Быстрый старт)

Для запуска приложения на локальном компьютере выполните следующие шаги:

1. **Склонируйте проект и перейдите в директорию:**
   ```bash
   git clone <ссылка-на-репозиторий>
   cd whats_the_rate
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   # Для Windows
   python -m venv venv
   venv\Scripts\activate
   
   # Для Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   python main.py
   ```
   
   *Приложение автоматически инициализирует базу данных и запустит локальный сервер (по умолчанию доступно по адресу `http://localhost:8080`).*
