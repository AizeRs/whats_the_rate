# What's the rate
Живая версия: https://aizer.lol

Сайт, на котором можно посмотреть курсы акций, криптовалют и фиатных валют и собрать из них свой портфель. Портфель считается в выбранной валюте (USD, EUR, GBP, JPY или CHF): видно, сколько он стоит сейчас, как изменился за день и как распределён между акциями, криптой и валютами.

Это мой пет-проект. Начинался как учебный проект на Flask в Яндекс Лицее, потом я довёл его до рабочего сайта и расширил функционал.

## Что умеет

- **Главная.** Сводка по трём рынкам: бегущая строка, таблица котировок с изменением за день и за неделю, капитализация, самые сильные движения дня. Если вы вошли в аккаунт, там же виден ваш портфель.
- **Акции.** Все тикеры бирж США из Finnhub с поиском по тикеру и названию и фильтром по первой букве. Цена загружается по запросу и обновляется сама, если устарела.
- **Криптовалюты.** 250 крупнейших монет по капитализации из CoinGecko.
- **Фиатные валюты.** Курсы ЕЦБ через Frankfurter и изменение к предыдущему дню.
- **Портфель.** В него можно добавить до 5 акций и любое количество монет и валют. Количество меняется прямо в таблице. Портфель может быть публичным, тогда им можно поделиться по ссылке `/portfolios/<логин>`.
- **API.** Стоимость портфеля можно получить запросом с личным ключом, ключ выдаётся в профиле. Подробности ниже.

## Как устроено обновление данных

У бесплатных API жёсткие лимиты. Finnhub, например, даёт около 60 запросов в минуту на весь сайт и отвечает про одну акцию за раз. Поэтому котировки лежат в SQLite, а свежие данные запрашиваются, только когда кто-то открывает страницу со старыми:

| Источник | Что берём | Считается устаревшим через |
|---|---|---|
| Finnhub | список тикеров, цены, капитализация | 15 минут (цена) |
| CoinGecko | топ-250 монет, изменение за 24 ч и 7 дней, график за неделю | 5 минут |
| Frankfurter (ЕЦБ) | курсы валют и история за неделю | 1 час |

Устаревшая цена подгружается в фоне, а таблица обновляется без перезагрузки страницы. Повторные попытки идут не чаще раза в минуту, чтобы не упереться в лимит. Время обновления показывается в часовом поясе пользователя.

## Стек

- Python 3, Flask, Flask-Login, Flask-WTF
- SQLAlchemy + SQLite
- Jinja2-шаблоны, Tailwind и немного обычного JavaScript
- `requests` для внешних API
- На сервере: gunicorn

## Запуск локально

```bash
git clone https://github.com/AizeRs/whats_the_rate.git
cd whats_the_rate

python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux / macOS

pip install -r requirements.txt
```

Файла `app/constants.py` в репозитории нет, потому что в нём лежат ключи. Создайте его сами:

```python
FINNHUB_APIKEY = 'ваш ключ Finnhub'   # бесплатный ключ: https://finnhub.io/register
SECRET_KEY = 'любая длинная случайная строка'
HOST = '0.0.0.0'
PORT = 5000
```

И запустите:

```bash
python main.py
```

Сайт откроется на http://localhost:5000. База `data/whats_the_rate.db` создастся сама при первом запуске.

На пустой базе криптовалюты и курсы валют подгрузятся при первом открытии главной. Список акций загружается кнопкой обновления на странице «Акции».

Для продакшена есть `wsgi.py`:

```bash
pip install gunicorn
gunicorn wsgi:app
```

## API

Ключ создаётся в профиле.

```
GET /api/portfolio_price?apikey=<ключ>&base_currency=EUR
```

Возвращает стоимость портфеля: `{"price": "1 234,56 €", "price_float": 1234.56}`. Параметр `base_currency` необязательный: по умолчанию берётся валюта из профиля.

```
GET /api/reload_portfolio?apikey=<ключ>
```

Обновляет цены всех активов в портфеле.

```
main.py, wsgi.py        точки входа: локальный сервер и gunicorn
app/blueprints/         маршруты: главная, рынки, портфель, авторизация, API
app/services/           запросы к внешним API и работа с базой
app/models/             модели SQLAlchemy
app/home.py             данные для главной
app/formatting.py       форматирование цен, дат и изменений
templates/              Jinja2-шаблоны
```

## Про ИИ

Текущие дизайн и фронтенд сайта разрабатывались совместно с ИИ (в основном Claude code, немного Antigravity и stitch). Но не в формате "создай мне сайт" одним запросом, а пошагово, начиная с дизайн-системы. Каждый интерфейс сначала рисовался на макете через stitch и Claude design, а затем уже переносился в код. Бэкенд, архитектуру, логику обновления данных и их обработку, при этом, я писал сам. Для нового фронтенда понадобилось расширить в разы бэкенд, т.к. получившиеся интерфейсы запрашивали гораздо больше данных, чем изначально предполагалось.
